# Dashboard & riwayat

## Story

Sebagai creator, saya ingin melihat progress minggu ini di beranda supaya saya tahu apakah target ide sudah tercapai.

Sebagai creator, saya ingin membuka riwayat konten yang sudah Posted untuk mereview apa yang sudah terbit.

## Acceptance criteria

- Dashboard shows greeting, week range, weekly goal progress, and in-progress items when any exist.
- Dashboard recommendations teaser links to full rekomendasi.
- Riwayat lists Posted items the user can access (owned or shared membership weeks), read-only preview.
- Posted items in planner detail stay read-oriented for history consistency.

## Out of scope

Analytics charts, export CSV, cross-account team dashboards.
