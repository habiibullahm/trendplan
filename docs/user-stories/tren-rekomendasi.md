# Tren & rekomendasi

## Story

Sebagai creator niche Couple Date Ideas, saya ingin melihat katalog ide dan rekomendasi supaya saya punya ide yang relevan untuk diplan.

## Acceptance criteria

- `/tren` lists seeded ideas as catalog cards: cover poster, title, hook, reason, format, niche; user **Pakai** into a planner day.
- Cards are idea rows (not a FYP/video player). No video, audio row, or visible trend score.
- `/rekomendasi` (and dashboard teaser) filters suggestions by the user’s niche. Rekomendasi uses the same full card; Beranda uses a dense row (cover, title, format) linking to `/tren#id`.
- User can add a trend-inspired idea into the planner from the product flows that support it.
- Niche changes in Akun retarget rekomendasi / tren defaults.

## Out of scope

Live TikTok FYP scrape, personalized ML ranking, paid trend APIs, video/audio on trend cards.
