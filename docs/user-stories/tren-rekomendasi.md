# Tren & rekomendasi

## Story

Sebagai creator niche Couple Date Ideas, saya ingin melihat tren mock dan rekomendasi supaya saya punya ide yang relevan untuk diplan.

## Acceptance criteria

- `/tren` lists seeded trends with media/caption/hashtag suggestions where provided.
- `/rekomendasi` (and dashboard teaser) filters suggestions by the user’s niche.
- User can add a trend-inspired idea into the planner from the product flows that support it.
- Niche changes in Akun retarget rekomendasi / tren defaults.

## Out of scope

Live TikTok FYP scrape, personalized ML ranking, paid trend APIs.
